# AutoHotkey v2 C++ Interpreter Documentation

## 1) Executive Summary

This repository contains the C++ implementation of the AutoHotkey v2 interpreter. Its primary purpose is to parse, interpret, and execute AutoHotkey v2 scripts, translating AHK commands and directives into corresponding Windows API (WinAPI) calls and internal logic to automate various tasks on the Windows operating system. This includes handling user input (keyboard and mouse), managing windows, interacting with the clipboard, and controlling processes. The application is built using MSBuild and targets Windows platforms.

The high-level architecture consists of several key components: a core application module responsible for initialization and the main message loop, a script parsing and execution engine, modules for interacting with the Windows GUI (windows, controls, messages), input handling (hooks, simulation), and various utility modules for file I/O, process management, and COM interactions. These components collaborate by maintaining a global application state and dispatching WinAPI calls based on the interpreted AHK script logic.

This document covers the C++ code only and does not include any AHK v2 scripts.
