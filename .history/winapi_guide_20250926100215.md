# AutoHotkey WinAPI Developer Guide

## Overview

This guide provides comprehensive documentation of Windows API (WinAPI) usage patterns in the AutoHotkey C++ interpreter. It's designed as both a reference for developers working on this codebase and a practical guide for implementing system-level automation in C++ applications.

## Key WinAPI Areas in AutoHotkey

### 1. Hooks & Input Processing
- SetWindowsHookEx(WH_KEYBOARD_LL) - Low-level keyboard interception
- SetWindowsHookEx(WH_MOUSE_LL) - Low-level mouse interception

### 2. Input Simulation  
- SendInput() - Modern input synthesis
- keybd_event(), mouse_event() - Legacy methods

### 3. Window Management
- FindWindowEx(), SetActiveWindow() - Window operations
- GetWindowText(), SetWindowText() - Window properties
- SendMessage(), PostMessage() - Window messaging

### 4. Process & Threading
- CreateThread() with THREAD_PRIORITY_TIME_CRITICAL for hook thread
- PostThreadMessage() for inter-thread communication
- CreateMutex() for hook instance prevention

### 5. File I/O
- CreateFile(), ReadFile(), WriteFile() - File operations
- MultiByteToWideChar(), WideCharToMultiByte() - Encoding conversion
