# AutoHotkey v2.1-alpha.32

**Released:** 2026-09-12

## Overview

Alpha.32 is a small release: one new Gui property and three fixes, plus the v2.0
merge that arrived with it. It landed four days after this fork merged alpha.31, and
the fork skipped it until the alpha.33 catch-up on 2026-10-08 (merged together with
alpha.33 and the upstream commits through 2026-10-07).

## New features

### `Gui.FontHandle`

Returns the `HFONT` the Gui currently applies to new controls, i.e. the font that
`Gui.SetFont` selected. Useful for custom-draw callbacks and for `SendMessage`
`WM_SETFONT` to controls created outside the Gui object.

```ahk
#Requires AutoHotkey v2.1-alpha.32
g := Gui()
g.SetFont("s11", "Segoe UI")
hFont := g.FontHandle
```

Feature-detect across builds with the maybe operator: `(g.FontHandle?) ??
SendMessage(0x31, 0, 0, g)` falls back to `WM_GETFONT` on alpha.31 and earlier.

## Fixes

- `a := b` where `b` holds a virtual reference (a `PropRef` or VarRef) now assigns
  the dereferenced value instead of throwing.
- `Until` as the last line of a `#Module` section no longer crashes the loader.
- `Gui.Move` no longer DPI-scales the X and Y arguments; only width and height
  are scaled, matching `Gui.Show`.
- `GuiType::Move` fix for owned windows and `FileSetTime` opening with
  `FILE_WRITE_ATTRIBUTES` (from the v2.0 merge).

## Fork notes

- Verified on `2.1-alpha.33+Console`: `Gui.FontHandle` returns a non-zero handle
  and the `(g.FontHandle?) ??` fallback compiles on both sides.
- No fork source touched by this release conflicted with the merge.
